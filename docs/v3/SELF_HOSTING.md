# Self-hosting

The setup guide is the main [README](../../README.md): fork the repository, import the fork in Cloudflare, fill in one setup page, then add domains in Admin → Domains. Update with **Sync fork** on GitHub; notes are in [UPGRADING.md](../UPGRADING.md).

Keep your fork unmodified (see [LICENSE](../../LICENSE)): all settings live in the app. Keep a copy of `PROVIDER_CREDENTIAL_KEY` outside Cloudflare.
